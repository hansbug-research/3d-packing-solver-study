# 本地实测协议

## 目标

区分四个问题：候选组件能否安装；能否在限定资源内求解；输出是否通过独立几何校验；业务约束是否由求解器原生保证。

## 资源边界

- Python 3.12 独立虚拟环境。
- 单次启发式测试 30 秒、精确测试 60 秒。
- `OMP_NUM_THREADS=1`、`OPENBLAS_NUM_THREADS=1`、`MKL_NUM_THREADS=1`。
- Python/CLI 进程虚拟内存上限 4 GiB；测试数据最多 100 件，先跑 10--30 件烟雾实例。
- 使用固定随机种子；记录 wall time 与最大常驻内存。

## 判定

1. 完整性：输入的必装件均出现且不重复。
2. 几何：每件在容器边界内，任意两件的轴对齐包围盒不相交。
3. 方向：输出尺寸必须属于该件允许的离散旋转集合。
4. 容量：容器总重量不超限。
5. 工况：支撑、承压、重心、轴荷、装卸顺序分别核验；组件未建模的约束不得因样例恰好满足而标为“支持”。
6. 最优性：只有求解器给出可验证界或完整搜索证明时才写“已证明最优”；启发式只比较可行性、成本和装载率。

## 边界

主测试针对正交装箱（六种轴向旋转的子集）。任意角度属于连续非凸碰撞优化，另设技术路线，不能用正交实例外推。
